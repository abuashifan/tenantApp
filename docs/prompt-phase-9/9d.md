TUJUAN:
Membuat backend Delivery Order sebagai dokumen pengiriman.
Delivery Order bisa dibuat dari Sales Order atau dibuat langsung.
Di Phase 9, Delivery Order belum membuat stock movement dan belum mengurangi stok.

RULES:

- Delivery Order bisa dibuat dari Sales Order.
- Delivery Order bisa dibuat langsung.
- sales_order_id nullable.
- sales_order_line_id nullable di line.
- Delivery Order tracking delivered_quantity.
- Delivery Order update delivered_quantity di Sales Order line jika berasal dari Sales Order.
- Delivery Order belum membuat stock_movement.
- Delivery Order belum mengurangi stok.
- Delivery Order belum membuat COGS journal.
- Delivery Order bisa menjadi source Sales Invoice di Phase 9F.
- Partial delivery harus didukung.
- Multiple delivery orders dari satu Sales Order harus didukung.
- Quantity delivery tidak boleh melebihi remaining quantity Sales Order.
