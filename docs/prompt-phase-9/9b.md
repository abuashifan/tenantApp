TUJUAN:
Membuat backend Sales Quotation/Penawaran Penjualan.
Quotation adalah dokumen penawaran, tidak membuat jurnal, tidak membuat piutang, dan tidak mengubah stok.

RULES:

- Quotation bisa dibuat langsung.
- Quotation bisa dikonversi ke Sales Order nanti di Phase 9C.
- Quotation tidak membuat journal entry.
- Quotation tidak mengubah stok.
- Quotation boleh punya discount.
- Quotation boleh punya tax flag.
- Quotation line boleh punya department_id/project_id optional.
- Quotation harus tenant-aware.
- Quotation harus support revision, audit log, permission, source fields nullable.

STATUS:

- draft
- sent
- approved
- accepted
- rejected
- expired
- cancelled
- converted
