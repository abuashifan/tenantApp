TUJUAN:
Membuat backend Sales Invoice/Faktur Penjualan.
Sales Invoice adalah dokumen accounting utama sales yang membuat Accounts Receivable dan Sales Revenue saat posted.

RULES FINAL:

- Sales Invoice bisa dibuat dari Sales Order.
- Sales Invoice bisa dibuat dari Delivery Order.
- Sales Invoice bisa dibuat dari Proforma Invoice.
- Sales Invoice bisa dibuat langsung.
- Sales Invoice mengambil DP dari Sales Order jika source berasal dari Sales Order.
- Sales Invoice tidak input DP baru.
- Sales Invoice boleh input/edit discount final sebelum posted.
- Discount final di Sales Invoice dipakai untuk accounting.
- Sales Invoice membuat AR/Revenue/Tax journal saat posted.
- Sales Invoice membuat deposit allocation journal jika DP applied.
- Sales Invoice tidak membuat stock movement di Phase 9.
- Sales Invoice tidak membuat COGS journal di Phase 9.
- Jika source Delivery Order, jangan buat stock movement lagi.
- Stock movement dan COGS ditunda ke Phase 12.

POSTING LOGIC:
Saat post invoice:

1. Validate status.
2. Validate period not locked.
3. Validate account mappings:
   - accounts_receivable
   - sales_revenue
   - output_tax if tax enabled
   - customer_deposit if DP applied
4. Create journal:
   Dr Accounts Receivable = grand_total
   Cr Sales Revenue = net sales amount
   Cr Output Tax Payable = tax_total if any
5. If applied_down_payment_amount > 0:
   Dr Customer Deposit
   Cr Accounts Receivable
6. Update invoice status posted / partially_paid if DP applied / paid if fully covered.
7. Update source Sales Order invoiced_quantity if source order.
8. Update Delivery Order invoiced status if source delivery order.
9. Update Proforma status converted if source proforma.
10. Do not create stock movement.
11. Do not create COGS journal.

DP APPLY RULE:
If invoice is from Sales Order:

- find posted customer_deposits related to sales_order_id
- calculate available remaining_amount
- apply up to invoice grand_total unless request defines lower applied amount
- create customer_deposit_allocations
- reduce remaining_amount
- create deposit allocation journal
