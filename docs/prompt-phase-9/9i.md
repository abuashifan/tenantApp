RULES:

- Sales Return bisa dibuat dari Sales Invoice.
- Sales Return bisa dibuat dari Delivery Order jika setting allows.
- Sales Return bisa dibuat langsung hanya dengan permission khusus.
- Retur mengurangi AR jika invoice belum lunas.
- Jika invoice sudah lunas, retur bisa menghasilkan customer credit nanti advanced; untuk MVP bisa block atau create credit placeholder.
- Stock return belum mengubah stok di Phase 9.
- Stock return integration masuk Phase 12.
- Sales Return membuat journal contra revenue/AR.
- Tidak membuat stock movement.
- Tidak membuat inventory return journal.
