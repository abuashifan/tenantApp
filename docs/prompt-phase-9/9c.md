TUJUAN:
Membuat backend Sales Order/Pesanan Penjualan.
Sales Order bisa dibuat dari Quotation atau dibuat langsung.
Sales Order boleh input discount.
Sales Order boleh input down payment section.
Down payment aktual disimpan di customer_deposits table, bukan langsung sebagai angka utama sales_orders.

RULES:

- Sales Order tidak membuat jurnal penjualan.
- Sales Order tidak membuat piutang.
- Sales Order tidak mengubah stok.
- Sales Order tidak membuat stock movement.
- Sales Order bisa dibuat dari quotation.
- Sales Order bisa dibuat langsung.
- quotation_id nullable.
- quotation_line_id nullable di line.
- Sales Order punya has_down_payment boolean.
- Jika has_down_payment true dan payload down_payment diisi, backend membuat Customer Deposit draft/posted sesuai setting.
- Customer Deposit tetap entity/table terpisah.
- Jurnal DP:
  Dr Cash/Bank
  Cr Customer Deposit
- Jika belum ada service/table CustomerDeposit karena Phase 9H belum dikerjakan, buat minimal foundation customer_deposits yang dibutuhkan untuk nested DP, lalu Phase 9H melengkapinya.
- Jangan membuat Sales Invoice.
- Jangan membuat stock movement.
