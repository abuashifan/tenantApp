TUJUAN:
Membuat backend Vendor Bill / Purchase Invoice.
Vendor Bill adalah dokumen accounting utama purchase yang membuat Accounts Payable saat posted.

RULES FINAL:

- Vendor Bill bisa dibuat dari Purchase Order.
- Vendor Bill bisa dibuat dari Goods Receipt.
- Vendor Bill bisa dibuat langsung.
- Vendor Bill mengambil vendor deposit dari Purchase Order jika source berasal dari Purchase Order.
- Vendor Bill tidak input vendor deposit baru.
- Vendor Bill boleh input/edit discount final sebelum posted.
- Discount final di Vendor Bill dipakai untuk accounting.
- Vendor Bill membuat AP/Expense/Input Tax journal saat posted.
- Vendor Bill membuat vendor deposit allocation journal jika DP applied.
- Vendor Bill tidak membuat stock movement di Phase 10.
- Vendor Bill tidak membuat inventory valuation di Phase 10.
- Jika source Goods Receipt, jangan buat stock movement lagi.
- Stock movement dan inventory valuation ditunda ke Phase 12.

POSTING LOGIC:
Saat post bill:

1. Validate status.
2. Validate period not locked.
3. Validate account mappings:
   - accounts_payable
   - purchase_expense or inventory_interim
   - input_tax if tax enabled
   - vendor_deposit if DP applied
4. Create journal:
   Dr Purchase Expense / Inventory Interim = net purchase amount
   Dr Input Tax = tax_total if any
   Cr Accounts Payable = grand_total
5. If applied_vendor_deposit_amount > 0:
   Dr Accounts Payable
   Cr Vendor Deposit / Advance Payment
6. Update bill status posted / partially_paid if DP applied / paid if fully covered.
7. Update source Purchase Order billed_quantity if source order.
8. Update Goods Receipt billed status if source goods receipt.
9. Do not create stock movement.
10. Do not create inventory valuation journal.

DP APPLY RULE:
If bill is from Purchase Order:

- find posted vendor_deposits related to purchase_order_id
- calculate available remaining_amount
- apply up to bill grand_total unless request defines lower applied amount
- create vendor_deposit_allocations
- reduce remaining_amount
- create deposit allocation journal
