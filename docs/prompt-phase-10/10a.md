DISCOUNT CALCULATION RULES:
discount_type allowed:

- percent
- fixed_amount
- null

Validation:

- percent tidak boleh < 0 atau > 100
- fixed amount tidak boleh negatif
- discount_amount tidak boleh melebihi gross amount
- header discount tidak boleh melebihi subtotal setelah line discount

Calculation:

1. gross_amount = quantity \* unit_price
2. line discount dihitung dulu
3. subtotal_after_line_discount = gross - line_discount
4. header discount dihitung dari subtotal setelah line discount
5. tax dihitung setelah discount
6. grand_total = subtotal_after_discount + tax_total
