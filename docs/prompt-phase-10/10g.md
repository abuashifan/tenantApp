TUJUAN:
Membuat backend Purchase Return/Retur Pembelian.
Purchase Return mengurangi hutang atau mengurangi expense/purchase value.
Stock return belum mengubah stok di Phase 10.

RULES:

- Purchase Return bisa dibuat dari Vendor Bill.
- Purchase Return bisa dibuat dari Goods Receipt jika setting allows.
- Purchase Return bisa dibuat langsung hanya dengan permission khusus.
- Retur mengurangi AP jika bill belum lunas.
- Jika bill sudah lunas, retur bisa menghasilkan vendor credit nanti advanced; untuk MVP bisa block atau create credit placeholder.
- Stock return belum mengubah stok di Phase 10.
- Stock return integration masuk Phase 12.
- Purchase Return membuat journal AP/purchase return.
- Tidak membuat stock movement.
- Tidak membuat inventory return journal.

STATUS:

- draft
- approved
- posted
- void

JOURNAL:
Dr Accounts Payable
Cr Purchase Return / Expense Reduction
Cr Input Tax if tax active and applicable

Alternative jika project memakai debit/credit terpisah:
Dr Accounts Payable
Cr Purchase Return
Cr Input Tax Receivable
