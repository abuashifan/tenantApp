TUJUAN:
Membuat backend Purchase Request/Permintaan Pembelian.
Purchase Request adalah dokumen internal permintaan pembelian, tidak membuat jurnal, tidak membuat hutang, dan tidak mengubah stok.

RULES:

- Purchase Request bisa dibuat langsung.
- Purchase Request bisa dikonversi ke Purchase Order nanti di Phase 10C.
- Purchase Request tidak membuat journal entry.
- Purchase Request tidak membuat Accounts Payable.
- Purchase Request tidak mengubah stok.
- Purchase Request boleh punya estimated price.
- Purchase Request boleh punya department_id/project_id optional.
- Purchase Request harus tenant-aware.
- Purchase Request harus support revision, audit log, permission, source fields nullable.

STATUS:

- submitted

- rejected
- cancelled
- converted
